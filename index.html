Projetos

Sistema de futebol de robôs — RoboCup SSL

Sistema 6v6 completo para a Small Size League, com módulos desacoplados de visão, estratégia e decisão. Utiliza Memcached como barramento de dados em tempo real e eleição de líder atômica, com failover demonstrado em aproximadamente 3 segundos sobre Docker Swarm.

Cluster Sync — replicação e tolerância a falhas

Sistema distribuído com exclusão mútua por Ricart-Agrawala e replicação com primário dinâmico, implementado sobre sockets POSIX e threads, sem middleware. Detecção de falhas por timeout e teste de consistência entre réplicas.

C++17 Node.js Sockets POSIX

Sistema de controle de despesas

Aplicação full-stack para controle de despesas residenciais, com regras de negócio por faixa etária e exclusão em cascata. Desenvolvida como desafio técnico.

C# / .NET 8 EF Core React TypeScript

Análise empírica do problema da mochila

Comparação de três algoritmos exatos para o problema 0-1 com duas restrições: programação dinâmica, backtracking e branch-and-bound. Pipeline experimental em Python com testes estatísticos de Friedman e Wilcoxon.
